## ✨ Funcionalidades

- **Design futurista** com grade de fundo, efeito scanline e animações suaves
- **Tema Dark / Light** com alternância por botão e preferência salva no navegador
- **Seções completas** — Informações Pessoais, Formação, Experiência, Habilidades, Badges e Contato
- **Formulário de contato** integrado ao [Formspree](https://formspree.io), sem necessidade de back-end
- **100% estático** — apenas HTML, CSS e JS puro, sem frameworks ou dependências

## 📬 Formulário de contato

O formulário utiliza o [Formspree](https://formspree.io) para enviar mensagens diretamente ao e-mail do proprietário, sem nenhum servidor próprio.

Para configurar em um fork deste projeto:
1. Crie uma conta gratuita em [formspree.io](https://formspree.io)
2. Crie um novo form e copie o endpoint gerado
3. No `script.js`, substitua o endpoint na linha do `fetch`
